# Object Counting Using OpenCV

## Description
This project detects and counts objects in an image using Python and OpenCV.

## Technologies Used
- Python
- OpenCV
- Image Processing

## Features
- Converts images to grayscale
- Detects object edges and contours
- Counts detected objects
- Draws rectangles around detected objects

## Installation
Install the required library:

`pip install opencv-python`

## Usage
Place an image named `objects.jpg` in the project folder and run:

`python object_counting.py`

**Note:** This project is provided for learning purposes. Detection accuracy depends on image quality and how clearly objects are separated.
